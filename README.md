# Sistema de Votación Borda Automático 🗳️

Una aplicación web ligera diseñada para automatizar y simular elecciones utilizando el **Método de Borda** (Recuento de Borda).

## 📖 Sobre el Proyecto

El recuento de Borda es un sistema electoral de elección social en el que los votantes ordenan a los candidatos según sus preferencias, en lugar de votar por una única opción. Este enfoque permite capturar de manera más completa las preferencias del electorado y tiende a favorecer a candidatos de consenso, minimizando las paradojas que a menudo presentan los sistemas de mayoría simple. 

Este proyecto ofrece una interfaz intuitiva para cargar alternativas, ingresar las preferencias ordenadas y calcular automáticamente los puntajes finales, determinando al ganador de manera transparente.

## 🚀 Características Principales

* **Cálculo Automático:** Asignación de puntajes basada en el posicionamiento de cada candidato en la boleta de cada votante.
* **Interfaz Responsiva:** Diseño adaptado para funcionar perfectamente tanto en computadoras de escritorio como en dispositivos móviles.
* **Ejecución del Lado del Cliente:** Todo el procesamiento lógico se realiza directamente en el navegador, sin necesidad de bases de datos externas.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la aplicación.
* **CSS3:** Estilos visuales integrados para una interfaz limpia y responsiva.
* **JavaScript (Vanilla):** Lógica del algoritmo de Borda y manipulación dinámica del DOM.

## ⚙️ Cómo usarlo

1. Ingresa al enlace del proyecto.
2. Añade los candidatos o alternativas disponibles para la elección.
3. Ingresa la cantidad de votantes o las boletas con el orden de preferencia.
4. El sistema calculará y mostrará automáticamente la tabla de posiciones con los puntajes totales de cada alternativa.
